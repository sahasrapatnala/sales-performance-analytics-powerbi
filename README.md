
# Sales Performance Analytics Dashboard

## Project Overview
This project presents an interactive sales analytics dashboard built using Microsoft Power BI. It helps explore sales performance across products, countries, salespeople, and months.

## Dashboard Features
- **KPI Cards:** Total Revenue, Total Boxes Shipped, and Total Sales Transactions.
- **Monthly Sales Trend:** Tracks changes in sales over time.
- **Revenue by Product:** Compares revenue across products.
- **Revenue by Salesperson:** Examines salesperson performance.
- **Revenue by Country:** Compares sales across countries.
- **Interactive Filters:** Country and Product slicers allow users to explore the data.

## Tools Used
- Microsoft Power BI Desktop

## How to Use
1. Download the `.pbix` report from this repository.
2. Open it using Power BI Desktop.
3. Use the Country and Product slicers to explore the report.

## Project Files
- `SALES PERFORMANCE ANALYTICS.pbix` — Power BI report.
- `dashboard.png` — Dashboard preview.

- Creating KPI cards and interactive visualizations.
- Comparing performance across categories.
- Designing a dashboard for easier data exploration.
